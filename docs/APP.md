# Приложение для ПК (Windows)

`MT5-Agent.exe` — настольное приложение, которое делает работу с агентом «кнопочной»:
мастер настройки счёта, пошаговый запуск от проверки связи до демо-торговли, статус,
позиции, журнал сделок и аварийный стоп в одном окне. Внутри — то же ядро агента
(`src/mt5_agent`), что и в консоли: приложение ничего не считает само, оно управляет
агентом и показывает его состояние.

```
┌─────────────────────────────────────────────────────────────────────┐
│ 🤖 MT5 AI-Agent        [✅ РАБОТАЕТ]   [Демо] [Наблюдение] [Остановить]│
├─────────────────────────────────────────────────────────────────────┤
│ Настройка │ Быстрый старт │ Обзор │ Позиции │ Журнал │ Задачи │ Настройки │
└─────────────────────────────────────────────────────────────────────┘
```

Текущая рабочая пара — **AUDCAD** (`config/config.yaml` → `trading.symbols`).

---

## Как получить приложение

### Вариант 1. Скачать готовый файл (Python не нужен)

1. Открой репозиторий на GitHub → вкладка **Actions** → **Сборка приложения (Windows)**
   → **Run workflow** (или скачай артефакт последнего запуска).
2. По завершении (10–20 минут) скачай **MT5-Agent-Windows.zip** внизу страницы запуска.
3. Распакуй архив в удобную папку (например `C:\MT5-Agent`) и запусти `MT5-Agent.exe`.

Внутри архива: сам `MT5-Agent.exe`, папка `config` с настройками, `.env.example`,
`ПРОЧТИ-МЕНЯ.txt` и документация.

### Вариант 2. Собрать самому на своём ПК

```powershell
# 1) окружение (нужен Python 3.10–3.13)
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1

# 2) собрать приложение
powershell -ExecutionPolicy Bypass -File .\scripts\build_exe.ps1

# 3) результат: MT5-Agent.exe в корне проекта (и в папке dist)
```

### Вариант 3. Без .exe — просто кнопки на существующем Python

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_gui.ps1
# ярлык на рабочем столе:
powershell -ExecutionPolicy Bypass -File .\scripts\start_gui.ps1 -CreateShortcut
```

Это тот же интерфейс, только запускается через `pythonw.exe`. Ничего собирать не нужно,
и антивирус не будет ругаться на упакованный файл.

## Первый запуск: что нажимать

### Вкладка «Настройка»

1. Впиши **логин, пароль и сервер ДЕМО-счёта** MetaTrader 5 (они видны в терминале при входе).
2. Путь к `terminal64.exe` можно оставить пустым, если терминал уже запущен.
3. Нажми **«Сохранить в .env»** — реквизиты запишутся в файл `.env` рядом с приложением
   (он в `.gitignore`, никуда не отправляется; приложение не пишет пароль в логи).
4. Нажми **«Проверить связь (check)»** — внизу появится отчёт: найден ли терминал,
   демо ли счёт, разрешена ли автоторговля, какие у AUDCAD `digits`/стоимость пункта.

Сначала должно быть готово окружение: терминал MT5 запущен, выполнен вход в демо-счёт,
нажата кнопка **AutoTrading**, а AUDCAD добавлен в «Обзор рынка».

### Вкладка «Быстрый старт»

Кнопка **«Запустить всё до бэктеста»** выполняет четыре шага для выбранного инструмента:

| Шаг | Что делает | Когда останавливается |
|---|---|---|
| 1. `check` | проверка окружения и связи | продолжает даже с замечаниями |
| 2. `fetch` | скачивает бары AUDCAD и **реальные параметры символа** (`--save-specs`) | при ошибке подключения |
| 3. `train` | обучает модель с walk-forward проверкой | продолжает, но показывает AUC |
| 4. `backtest` | считает результат с издержками и выносит вердикт | при отрицательном вердикте демо НЕ предлагается |

Галочка **«Песочница (без MT5, синтетика)»** прогоняет шаги 1, 3 и 4 на выдуманных
данных: терминал не нужен, но и выводы о доходности делать нельзя — это проверка того,
что программа работает.

После положительного вердикта приложение предложит запустить **демо-торговлю**.
Перед запуском оно показывает список замечаний (нет `.env`, нет модели, включён kill
switch) и просит подтверждение.

### Вкладки «Обзор», «Позиции», «Журнал», «Задачи», «Настройки»

* **Обзор** — equity, баланс, результат дня, просадка, входы за день, сигналы последнего
  цикла с причинами («вне торговых сессий 00:00–06:00, 13:00–19:00 UTC», «спред шире 30 пт»).
* **Позиции** — что открыто, где стопы и тейки, плавающий результат и список блокировок.
* **Журнал** — события (входы, закрытия, перенос стопа, блокировки) и лог агента.
* **Задачи** — те же команды (`check`/`fetch`/`train`/`backtest`) по отдельности.
* **Настройки** — текущие лимиты риска (только чтение) и кнопки открытия `config.yaml`,
  папки проекта и `reports`.

## Управление агентом: две разные остановки

| Кнопка | Что произойдёт | Когда использовать |
|---|---|---|
| **Остановить мягко** | агент доработает текущий цикл и выйдет. **Позиции не закрываются** — они остаются под защитой стоп-лоссов у брокера | плановые работы: обновление кода, перезагрузка VPS |
| **Kill switch** | агент немедленно закроет **все свои** позиции и остановится, флаг остановки сохранится на диске | нештатная ситуация |
| **Снять стоп** | снимает kill switch и флаг остановки | только когда причина устранена и понятна |

Обе команды доступны и из консоли: `MT5-Agent.exe --cli stop` и
`MT5-Agent.exe --cli kill` / `unkill`.

## Что приложение НЕ делает (намеренно)

* **Не запускает реальный счёт.** В окне доступны только `shadow` (наблюдение без
  ордеров) и `paper` (демо). Реальный счёт включается тремя подтверждениями и только
  из консоли: `MT5-Agent.exe --cli run --mode live --i-understand-live`.
* **Не меняет риск-лимиты одним щелчком.** Лимиты живут в `config.yaml` и применяются
  после перезапуска агента. Решение «увеличить риск» не должно приниматься в просадке.
* **Не считает ничего сама.** Панель только дёргает контроллер, а тот запускает тот же
  CLI и читает те же файлы состояния, что и консоль, — расхождению взяться неоткуда.
* **Не работает без терминала.** `MetaTrader5` — это связь с запущенным MT5, а не
  самостоятельный доступ к брокеру.

## Двурежимность: одно приложение — окно и консоль

`MT5-Agent.exe` без аргументов открывает окно, с флагом `--cli` работает как обычная
команда агента:

```powershell
.\MT5-Agent.exe --cli check
.\MT5-Agent.exe --cli fetch --symbol AUDCAD --bars 20000 --save-specs
.\MT5-Agent.exe --cli train --symbol AUDCAD
.\MT5-Agent.exe --cli backtest --symbol AUDCAD --days 180
.\MT5-Agent.exe --cli run --mode paper
.\MT5-Agent.exe --cli stop
.\MT5-Agent.exe --cli kill --reason "остановка"
.\MT5-Agent.exe --cli status
```

Это нужно, потому что внутри `.exe` нельзя вызвать `python -m mt5_agent`: приложение
запускает само себя с флагом `--cli`. Поэтому же в `.exe` есть и консольные команды —
планировщик Windows может запускать те же задачи без установленного Python.

## Ограничения, о которых стоит знать

* **`.exe` не самодостаточен.** Рядом должны лежать `config\` (с `config.yaml`) и `.env`;
  папка `models\` создаётся при обучении. Поэтому запускай приложение из корня проекта
  (или из распакованного архива, где эти папки уже есть).
* **Антивирусы** иногда помечают файлы, упакованные PyInstaller'ом, как подозрительные
  (ложное срабатывание). Если это мешает — используй вариант 3 (ярлык на `pythonw.exe`):
  интерфейс тот же, упаковки нет.
* **Приложение — не служба.** Режим 24/7 обеспечивается задачами планировщика
  (`scripts\register_tasks.ps1`) и сторожем heartbeat. Окно можно закрывать: агент,
  запущенный из панели, продолжает работать отдельным процессом.
* **С телефона управлять нельзя.** Для удалённого присмотра используй дашборд
  (`tools\dashboard.py`, режим «только чтение») и уведомления в Telegram.
