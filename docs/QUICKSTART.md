# Быстрый старт: от нуля до демо-торговли

Инструкция для Windows, рабочая пара — **AUDCAD**. Рассчитана на 20–30 минут (без учёта
скачивания Python и терминала MT5). Всё делается в PowerShell.

> Если не хочется работать в консоли — есть **приложение с кнопками**:
> [`docs/APP.md`](APP.md). Оно делает те же шаги (мастер настройки счёта, «быстрый
> старт» из четырёх шагов, запуск демо-торговли), но мышкой.

Если какой-то шаг не сработал — смотри раздел «Если что-то не работает» в конце.

---

## Шаг 0. Что должно быть готово

| Что | Где взять | Зачем |
|---|---|---|
| Windows 10/11 (или Windows VPS) | — | `MetaTrader5` существует только под Windows |
| Python **3.10–3.13** | <https://www.python.org/downloads/windows/> | под него есть колесо `MetaTrader5` |
| Терминал **MetaTrader 5** | у твоего брокера | исполнение ордеров и данные |
| **ДЕМО-счёт** в MT5 | у брокера, 1 клик | на нём и будем проверять всё |

При установке Python обязательно поставь галочку **«Add python.exe to PATH»**.

> Рекомендую Python **3.11** или **3.12**. На 3.14 колёса тоже есть, но остальные
> библиотеки могут отставать.

## Шаг 2. Установка окружения (одна команда)

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

Что произойдёт: создастся `.venv`, установятся зависимости (включая `MetaTrader5`),
скопируется `.env.example` → `.env`. В конце скрипт сам напишет, что делать дальше.

Если PowerShell ругается на политику запуска — используй именно эту команду с
`-ExecutionPolicy Bypass`, ничего в системе менять не нужно.

## Шаг 3. Заполнить `.env`

```powershell
notepad .env
```

Впиши реквизиты **ДЕМО-счёта** (логин, пароль и сервер видны в MT5 при входе):

```ini
MT5_LOGIN=12345678
MT5_PASSWORD=пароль_от_демо
MT5_SERVER=MetaQuotes-Demo
MT5_TERMINAL_PATH=C:\Program Files\MetaTrader 5\terminal64.exe
```

`MT5_TERMINAL_PATH` можно оставить пустым, если терминал у тебя уже запущен — агент
подключится к активному. Блок `MT5_REAL_*` сейчас **не заполняй**.

Файл `.env` не попадает в git — пароли никуда не уедут.

## Шаг 4. Подготовить терминал MT5

1. Запусти MT5 и войди в **ДЕМО-счёт**.
2. Включи кнопку **«Алготрейдинг» / AutoTrading** на верхней панели (она должна стать зелёной).
3. Проверь: **Сервис → Настройки → Советники → «Разрешить автоматическую торговлю»**.
4. В «Обзоре рынка» добавь нужные символы (например, `EURUSD`) — правой кнопкой →
   «Показать все» → найди и добавь.

Терминал должен быть **запущен всё время, пока работает агент** — агент общается
именно с ним, а не с сервером брокера напрямую.

## Шаг 6. Скачать данные с брокера

```powershell
.\.venv\Scripts\python.exe -m mt5_agent fetch --bars 20000 --save-specs
```

Появится `data\AUDCAD_M15.csv` (бары) и `data\symbol_specs.yaml` (параметры символа).
Второй файл важен: в бэктесте риск считается по **твоим** значениям, а не по «средним

## Шаг 7. Обучить модель

```powershell
.\.venv\Scripts\python.exe -m mt5_agent train --symbol AUDCAD
```

Займёт от нескольких секунд до пары минут. Отчёт сохранится в
`reports\train_AUDCAD_M15.txt`.

Смотри в отчёте **два числа**:

* `AUC на отложенном тесте` — если около 0.50, модель не отличает движение от шума;
* таблицу «порог входа → ожидаемый результат» — есть ли там строки с «годных: да».

Нормальный результат «модель плохая» — это тоже результат. Он означает: эту идею
нельзя нести на реальные деньги.

## Шаг 8. Бэктест (главная проверка)

```powershell
.\.venv\Scripts\python.exe -m mt5_agent backtest --symbol AUDCAD --days 180
```

В конце отчёта — вердикт:

* **✅ можно тестировать дальше на демо** — метрики (число сделок, profit factor,
  просадка, матожидание) прошли пороги из конфига;
* **⛔️ НЕ ГОДИТСЯ для торговли** — в студию не выходим, правим идею (признаки,
  таймфрейм, горизонт), а не пороги.

Отчёт: `reports\backtest_AUDCAD_M15.txt` и `.json`.

## Шаг 9. Демо-торговля

Сначала «холостой» прогон — один цикл, без ордеров:

```powershell
.\.venv\Scripts\python.exe -m mt5_agent run --once --dry-run
```

Потом полноценная демо-торговля (ордера улетают, но на ДЕМО-счёте):

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_agent.ps1 -Mode paper
```

Агент работает циклами (по умолчанию раз в 60 секунд), сам считает сигналы, ставит
ордера со стопом и тейком, ведёт дневные лимиты. Остановить — `Ctrl+C` в окне.

> Учти: для AUDCAD заданы **два окна ликвидности** (UTC): `00:00–06:00` (Токио/Сидней
> со стороны AUD) и `13:00–19:00` (Нью-Йорк со стороны CAD). В остальные часы агент
> новых сделок не открывает — это не поломка, а фильтр «тонкого рынка». Менять окна
> можно в `config\config.yaml` → `session_windows`.

Смотреть, что происходит:

```powershell
# в отдельном окне:
.\.venv\Scripts\python.exe -m mt5_agent status
.\.venv\Scripts\python.exe tools\dashboard.py
# затем открой http://127.0.0.1:8787
```

Остановка агента — два разных действия, не путай:

```powershell
# 1) МЯГКО: доработает текущий цикл и выйдет. Позиции НЕ закрываются —
#    они остаются под защитой стоп-лоссов у брокера.
.\.venv\Scripts\python.exe -m mt5_agent stop --reason "плановое обслуживание"

# 2) АВАРИЙНО: закроет ВСЕ свои позиции и встанет (для нештатной ситуации).
.\.venv\Scripts\python.exe -m mt5_agent kill --reason "останавливаю вручную"

# снять аварийный стоп: ... unkill
```

В панели управления это кнопки «Остановить мягко» и «Kill switch».

## Шаг 10. Приложение с кнопками вместо консоли (по желанию)

Если удобнее нажимать кнопки, чем писать команды — есть настольное приложение:
мастер настройки счёта, «быстрый старт» (проверка → данные → обучение → бэктест → демо),
статус, позиции, журнал и аварийный стоп. Полное описание: [`docs/APP.md`](APP.md).

Получить приложение можно тремя способами: скачать готовый `MT5-Agent.exe` из
GitHub Actions (Python не нужен), собрать локально (`build_exe.ps1`) или просто запустить
интерфейс на уже установленном Python:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_gui.ps1
# или из CLI:      .\.venv\Scripts\python.exe -m mt5_agent panel
# ярлык на раб. столе:  ...start_gui.ps1 -CreateShortcut
```

Откроется окно с вкладками:

* **Обзор** — статус (работает/остановлен/kill switch), equity, результат дня,
  просадка, реализовано сегодня, сигналы последнего цикла;
* **Позиции** — что открыто, где стопы и тейки, плавающий результат, причины
  блокировок входа;
* **Журнал** — последние события (входы, закрытия, стопы, блокировки) и лог агента;
* **Задачи** — кнопки `check`, `fetch`, `train`, `backtest` с выводом прямо в окне;
* **Настройки** — текущие лимиты риска (только чтение) и кнопки «открыть config.yaml /
  папку проекта / reports».

Кнопки вверху: **Демо-торговля**, **Наблюдение**, **Проверить один цикл** (без ордеров),
**Остановить мягко**, **Kill switch**, **Снять стоп**.

Важные особенности:

* панель запускает агента **отдельным процессом** — закрытие окна агента не
  останавливает (и наоборот: агент продолжит работать, если панель закрыта);
* **реальный счёт из панели недоступен** — только консоль и три подтверждения
  (см. `docs/SAFETY.md`). Это осознанное ограничение, а не недоделка;
* лимиты риска в панели не редактируются: меняешь `config.yaml` и перезапускаешь
  агента. Так решение «увеличить риск» не принимается одним нажатием в просадке;
* `.exe` двурежимный: двойной щелчок — окно панели, `MT5-Agent.exe --cli train --symbol AUDCAD`
  — обычная команда агента (это позволяет запускать задачи из планировщика без Python);
* рядом с `.exe` обязательно должны лежать `config\` и `.env` — приложение читает их
  из своей папки.

## Шаг 11. Режим 24/7 на VPS (когда демо уже показало себя)

Запуск от имени администратора:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\register_tasks.ps1 -Mode paper
```

Создадутся задачи планировщика: watchdog (каждые 5 минут проверяет heartbeat и
поднимает зависшего агента) и дашборд на `http://127.0.0.1:8787`.

Реальный счёт сюда **специально не входит**: его запускают руками, осознанно и
после чек-листа из `docs/SAFETY.md` (демо 1–3 месяца, отдельный счёт, три барьера).

## Если что-то не работает

| Симптом | Причина | Что делать |
|---|---|---|
| `Python 3.10–3.13 не найден` | Python не установлен или не в PATH | установи Python 3.11/3.12 с галочкой «Add to PATH», перезапусти PowerShell |
| Skill-ошибка вида `No module named MetaTrader5` | колесо не подошло к версии Python | `Remove-Item .venv -Recurse -Force`, затем пересоздай окружение на Python 3.11/3.12 через `install.ps1` |
| `Не заданы учётные данные MT5 (MT5_LOGIN в .env)` | не заполнен `.env` | открой `.env` и впиши логин/пароль/сервер демо-счёта |
| `initialize() вернул False` | терминал закрыт, не тот путь или выключен AutoTrading | запусти MT5, войди в счёт, включи AutoTrading, проверь `MT5_TERMINAL_PATH` |
| `терминал не подключён к торговому серверу` | нет интернета / терминал не вошёл в счёт | проверь связь и вход в терминале |
| `ОСТАНОВКА ПО БЕЗОПАСНОСТИ: Режим paper предполагает ДЕМО-счёт` | в `.env` указан реальный счёт | для демо-режима нужен именно демо-логин (или запусти `-Mode shadow` — он вообще не торгует) |
| `нет обученной модели ... обучение: python -m mt5_agent train` | шаг 7 пропущен | выполни `train`, затем запусти снова |
| В бэктесте 0 сделок | вероятности не дотягивают до порога / отфильтрована сессия | посмотри таблицу порогов в `reports\train_*.txt`; проверь окна `session_windows` в `config\config.yaml` |
| Кракозябры в консоли | старая консоль Windows | используй **Windows Terminal** или PowerShell 7; либо перед запуском `chcp 65001` |
| Скрипт `.ps1` не запускается | политика выполнения | всегда запускай с `powershell -ExecutionPolicy Bypass -File .\scripts\...` |
| Агент «молчит», сделок нет | вне сессии по UTC или сработал лимит | `python -m mt5_agent status` покажет причину по каждому символу |
| Панель не открывается: `No module named tkinter` | Python установлен без tcl/tk | переустанови Python с python.org, оставив галочку «tcl/tk and IDLE», и пересоздай `.venv` |
| Панель: «Kill switch активен», запуск не идёт | в `state\KILL_SWITCH` лежит файл стопа | нажми в панели «Снять стоп» (или `python -m mt5_agent unkill`), предварительно поняв причину |
| Панель: «нет модели для AUDCAD» | не выполнен `train` | вкладка «Задачи» → `train` (нужны данные: сначала `fetch`) |
| Хочу остановить, но не закрывать позиции | нужна мягкая остановка | кнопка «Остановить мягко» / `python -m mt5_agent stop` (не `kill`!) |
| AUDCAD: «вне торговых сессий» почти весь день | так заданы окна ликвидности | это норма: `00:00–06:00` и `13:00–19:00` UTC; меняется в `session_windows` |
| AUDCAD: «спред шире 30 пт» | узкое время (ролловер, вечер пятницы) | подожди окна ликвидности; при желании подними `max_spread_points` — но помни, что это увеличит издержки |
| Размер лота по AUDCAD больше, чем «привычно по EURUSD» | пункт AUDCAD дешевле (валюта прибыли CAD) | это правильно: лот считается от риска, а не «как у EURUSD» |

## Мини-шпаргалка команд

```powershell
# служебное
.\.venv\Scripts\python.exe -m mt5_agent check                 # окружение и связь
.\.venv\Scripts\python.exe -m mt5_agent status                # что сейчас делает агент
.\.venv\Scripts\python.exe -m pytest -q                       # 117 тестов, без MT5

# данные и модель
.\.venv\Scripts\python.exe -m mt5_agent fetch --bars 20000 --save-specs
.\.venv\Scripts\python.exe -m mt5_agent fetch --symbol GBPUSD --timeframe H1
.\.venv\Scripts\python.exe -m mt5_agent train --symbol AUDCAD
.\.venv\Scripts\python.exe -m mt5_agent backtest --symbol AUDCAD --days 180

# торговля
.\.venv\Scripts\python.exe -m mt5_agent run --once --dry-run   # один цикл без ордеров
powershell -ExecutionPolicy Bypass -File .\scripts\start_agent.ps1 -Mode shadow   # только наблюдение
powershell -ExecutionPolicy Bypass -File .\scripts\start_agent.ps1 -Mode paper    # демо-ордера

# панель управления (кнопки вместо команд)
powershell -ExecutionPolicy Bypass -File .\scripts\start_gui.ps1   # окно с кнопками
powershell -ExecutionPolicy Bypass -File .\scripts\start_gui.ps1 -CreateShortcut
.\.venv\Scripts\python.exe -m mt5_agent panel                      # то же из CLI

# контроль и остановка
.\.venv\Scripts\python.exe tools\dashboard.py                  # http://127.0.0.1:8787 (только чтение)
.\.venv\Scripts\python.exe -m mt5_agent stop --reason "план"   # мягко: доработает цикл, позиции не тронет
.\.venv\Scripts\python.exe -m mt5_agent kill --reason "стоп"   # аварийно: закрыть свои позиции и встать
.\.venv\Scripts\python.exe -m mt5_agent unkill                 # снять стоп

# без MT5 (проверка программы)
.\.venv\Scripts\python.exe tools\demo_cycle.py --cycles 40 --step 3 --quiet
```
