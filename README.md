Три коротких вертикальных ролика по пользовательскому рассказу: русский, английский и французский. Это **сокращённая адаптация**, а не дословная аудиокнига.

## Что именно сделано

Это монтаж из отдельных сгенерированных фотореалистичных изображений с плавным движением виртуальной камеры, типографикой и синхронизированной озвучкой/звуковой атмосферой. Это **не** видео с реально движущимися актёрами и **не** точный фонемный lip-sync: ни полноценную физику движения тел, ни синхронизацию губ по кадрам неподвижные исходные изображения обеспечить не могут.

## Сборка

Исходные изображения лежат в `assets/`, языковые записи — в `audio/`. Чтобы повторить сборку (Linux, Python 3.11+):

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python make_videos.py ru en fr
```

Промежуточные файлы создаются в `.cache/workday/` и не добавляются в репозиторий.
