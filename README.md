# Work-Day — AI Trading Agent для MetaTrader 5 (AUD/CAD)

Полноценное приложение автоматической торговли с архитектурой **LLM
Multi-Agent AI**: центральная LLM координирует трёх специализированных
AI-агентов, решения проходят через детерминированный Risk Manager, а
исполнение выполняет отдельный MT5 Execution Engine.

**Приоритет системы: БЕЗОПАСНОСТЬ → КОНТРОЛЬ → АНАЛИЗ → РЕШЕНИЕ → ИСПОЛНЕНИЕ.**

---

## Архитектура

```
MARKET DATA (MT5)
   ↓
AI AGENT #1: MARKET ANALYST      — тренд, сила, вероятности, волатильность,
   ↓                               уровни поддержки/сопротивления, зоны входа
AI AGENT #2: STRATEGY TRADER     — BUY/SELL/HOLD, entry, TP, SL, R:R
   ↓
AI AGENT #3: RISK & DECISION     — независимый контролёр сделки
   ↓
CENTRAL LLM TRADING MANAGER      — итоговое решение: BUY / SELL / HOLD / CLOSE
   ↓
RISK MANAGER (детерминированный) — жёсткие ограничения, которые LLM НЕ может обойти
   ↓
MT5 EXECUTION ENGINE             — единственный модуль, отправляющий ордера
   ↓
POSITION MONITOR → PROFIT TARGET → CLOSE POSITION → TRADE JOURNAL
```

### Ключевые гарантии безопасности
- **Одна позиция одновременно** — вторая никогда не открывается (контроль в
  Risk Manager, Execution Engine и MT5-шлюзе).
- **Лот не увеличивается системой** — только вручную пользователем и только
  в пределах `max_lot`.
- **LLM не имеет доступа к торговому API** — она возвращает структурированный
  JSON; ответ принудительно корректируется при попытке нарушить инварианты.
- **Конфликт агентов = HOLD** (AI Consensus): Market BUY + Strategy SELL →
  сделки нет.
- **Режим REAL** включается только после ввода фразы
  `REAL TRADING USES REAL MONEY.`
- Автозакрытие позиции при достижении заданной прибыли (по умолчанию
  $0.30–$0.80, настраивается вручную).

## Запуск

### Требования
- **Торговый сервер**: Windows + установленный терминал MetaTrader 5
  (пакет `MetaTrader5` существует только под Windows). Дашборд доступен
  с любого устройства в сети, включая Android-приложение.
- Python 3.10+.

### Установка
```bash
pip install -r requirements.txt
pip install -r requirements-windows.txt   # только на Windows: интеграция с MT5
python main.py                            # дашборд на http://0.0.0.0:8080
```

### Подключение к MT5
1. Откройте дашборд → **Settings → MT5 CONNECTION**.
2. Укажите (опционально) путь к `terminal64.exe`, логин, пароль и сервер
   (например, демо-счёт вашего брокера) → **CONNECT MT5**.
3. Символ `AUDCAD` резолвится автоматически, включая брокерские суффиксы
   (`.m`, `.pro`, `.ecn` и т.п.).

### Подключение к Bybit TradFi (демо и реальные сервера)
Bybit TradFi — это MT5-платформа внутри Bybit (форекс/металлы/индексы,
включая AUD/CAD), маржа в USDT.
1. Установите терминал MetaTrader 5 на компьютер, где запущено приложение.
2. В приложении Bybit: **TradFi → MT5-аккаунт** — создайте демо- или
   реальный счёт и скопируйте **MT5 ID** и **пароль**.
3. В дашборде выберите сервер (режим переключится автоматически):
   | Сервер | Назначение |
   |---|---|
   | `Bybit-Demo` | ДЕМО (виртуальные средства) |
   | `Bybit-Live`, `Bybit-Live2`…`Bybit-Live7` | РЕАЛЬНЫЕ (нужно подтверждение фразой) |
4. Введите MT5 ID/пароль → **CONNECT MT5** → **START**.

### Подключение LLM (опционально)
По умолчанию агенты работают в **детерминированном режиме** — реальный
расчёт индикаторов на реальных данных без внешней модели. Чтобы включить
LLM-слой: `Settings → LLM PROVIDER`:
- `openai` — модель OpenAI (нужен ключ или переменная `OPENAI_API_KEY`);
- `openai_compatible` — любая совместимая локальная/облачная модель
  (Ollama `http://127.0.0.1:11434/v1`, LM Studio, llama.cpp, vLLM…).

Провайдер заменяется без изменения торгового кода — только настройкой.

## Панель управления
Главный экран: цена/спред, счёт (баланс/эквити), открытая позиция и текущий
P/L, конвейер решений (AI MARKET → STRATEGY → RISK → LLM → CONFIDENCE),
кнопки **START / STOP / PAUSE / CLOSE POSITION / CLOSE ALL / DEMO⇄REAL**,
журнал сделок и решений, статистика дня.

Все критические параметры редактируются вручную: лот, мин/макс прибыль,
цель прибыли, SL, макс. спред, таймфреймы (M1…D1), порог AI confidence,
разрешение автоторговли, режим DEMO/REAL. AI параметры не меняет.

## Журнал и обучение
Каждый цикл сохраняется в SQLite (`data/workday.db`): рекомендации всех трёх
агентов, консенсус, решение центральной LLM, вердикт Risk Manager, факт
исполнения, цены, лот, результат сделки, причины. Эти данные доступны во
вкладке Journal и предназначены для анализа эффективности стратегии.

## Windows-приложение (прототип)

`desktop/launcher.py` — единый `.exe` для Windows (собирается автоматически
воркфлоу **Build Windows App (prototip)**): внутри вся торговая система,
дашборд открывается в родном окне, при запуске приложение проверяет наличие
новой версии в релизах `prototip-vX.Y` и показывает баннер обновления.

- Версия задаётся в `core/version.py` (`APP_VERSION`) и **повышается при
  каждой правке**; имя релиза/файла: `prototip-v<версия>`.
- Скачать последнюю сборку: вкладка **Releases** (тег `prototip-v…`) или
  ветка `prototip`.

## Мобильное приложение (Android)
- `android/` — исходники APK (панель управления в WebView, подключается к

- Альтернатива без сборки: дашборд — устанавливаемый **PWA**
  (Chrome → «Добавить на главный экран»).

Подробности: [android/README.md](android/README.md).

## Дисклеймер
Торговля сопряжена с риском. Используйте только демо-счёт до полного
понимания поведения системы. Режим REAL включается осознанно и только вами.
